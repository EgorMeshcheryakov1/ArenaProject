# Arena Project

Многопользовательская браузерная игра «Арена» — два игрока сражаются в режиме реального времени на круговой арене. Цель: вытолкнуть противника за её пределы с помощью рывков и вращения.

***
## Описание

Игра реализована на базе **FastAPI** с использованием **WebSocket** для двустороннего обмена данными между сервером и клиентами. Физика столкновений и движения рассчитывается на сервере с частотой **20 тиков/сек**. Клиентская часть находится в директории `static/` и отображается прямо в браузере.

Каждый игрок:
- автоматически вращается вокруг своей оси;
- может ускориться (рывок) в направлении текущего угла поворота;
- может управлять направлением вращения (влево / вправо / остановить).

Проигрывает тот, кто выкатится за границу арены. При отключении одного из игроков победа автоматически засчитывается сопернику.

***
## Игровой процесс

1. Оба игрока открывают игру в браузере и вводят имя.
2. Когда оба подключились — каждый нажимает кнопку **«Готов»**.
3. Начинается матч: игроки появляются с противоположных сторон арены.
4. **Управление:**

   | Действие | Управление |
   |----------|------------|
   | Рывок вперёд | Пробел / кнопка на экране |
   | Повернуть влево | ← / кнопка на экране |
   | Повернуть вправо | → / кнопка на экране |

5. Кто первым покинет пределы арены — проигрывает.
6. После матча оба игрока могут нажать **«Рестарт»** для нового раунда.
